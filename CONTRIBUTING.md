# Как да помогнеш

Благодарим, че искаш да направиш „Пътят към милиона“ по-добра! Най-ценното, което можеш да добавиш, са **добри въпроси**.

## 💡 Нови въпроси

1. Отвори файла на категорията в [`public/questions/`](public/questions).
2. Добави въпроса в края на масива `questions`. Вземи следващия свободен номер за `id`, например `hist-046`.
3. Пусни `npm run validate` и поправи всичко, което скриптът намери.
4. Отвори pull request.

Не ти се пише JSON? Използвай [формата за нов въпрос](https://github.com/Krumqnkata/become-millionaire/issues/new?template=new-question.yml).

### Какво прави един въпрос добър

- **Отговорът е безспорно верен** и може да се провери. Добави източник в PR-а.
- **Не остарява.** Без „кой е настоящият…“, „колко титли има…“ или рекорди, които може да паднат. Ако фактът зависи от дата, напиши датата във въпроса („през 2009 г.“).
- **Грешните отговори звучат правдоподобно.** Трите грешни отговора трябва да са от същия вид като верния: ако питаш за град, всички отговори са градове.
- **Без хитрости.** Въпросът проверява знание, а не внимателно четене.
- **Числата вървят във възходящ ред** (`["6", "8", "10", "12"]`), както в истинските шоута.
- **Обяснението е кратко и интересно.** Едно изречение, което учи нещо ново.

### Колко е труден въпросът

| `difficulty` | За кого                              | Пример                           |
| :----------: | ------------------------------------ | -------------------------------- |
|      1       | Знае го почти всеки, и деца.         | Коя е столицата на Франция?      |
|      2       | Обща култура от училище.             | Коя е най-дългата река в Европа? |
|      3       | Иска малко начетеност.               | Коя е столицата на Канада?       |
|      4       | Знаят го любителите на темата.       | Кой създава ядрото на Linux?     |
|      5       | За експерти и за въпроса за милиона. | Коя е столицата на Мианмар?      |

### Нова категория

1. Създай `public/questions/<id>.json` със същата структура (`category`, `name`, `questions`).
2. Добави категорията в [`manifest.json`](public/questions/manifest.json) с иконка.
3. По желание дай на някой от приятелите в [`src/game/lifelines.ts`](src/game/lifelines.ts) тази тема като любима.

## 🛠 Код

```bash
npm install
npm run dev     # разработка
npm run check   # lint + типове + въпроси + тестове
```

- Логиката на играта (`src/game`) не пипа DOM. Всяка промяна там трябва да има тест в `tests/`.
- Кодът е в TypeScript `strict` режим. Не използвай `any`.
- Форматирането е с Prettier (`npm run format`).
- Пиши кратки commit съобщения в повелително наклонение, например „Add mythology questions“.

## 🐞 Грешки

Намери ли грешен отговор или бъг? [Отвори issue](https://github.com/Krumqnkata/become-millionaire/issues/new?template=bug.yml) и напиши id-то на въпроса (виждаш го в JSON файла).
